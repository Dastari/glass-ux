# SessionNavSkeleton

The session list's loading rows: overline and title rows in their final box.

`import { SessionNavSkeleton } from "glass-ux/ai"`

[Live examples](https://dastari.github.io/glass-ux/components/session-nav-skeleton)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| rows | `number \| undefined` | See type | no | 6 | Number of placeholder title rows. Defaults to 6. |

Standard React DOM attributes and events are accepted wherever the component extends a native element. The online API page lists those inherited properties as well.
