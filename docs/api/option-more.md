# OptionMore

"1,272 more — refine your search", under a truncated result list.

`import { OptionMore } from "glass-ux/combobox"`

[Live examples](https://dastari.github.io/glass-ux/components/option-more)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| more | `number` | See type | yes | — | Count or definition of remaining items. |

Standard React DOM attributes and events are accepted wherever the component extends a native element. The online API page lists those inherited properties as well.
