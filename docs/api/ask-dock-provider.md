# AskDockProvider

Share pending questions and their resolutions between transcript markers and the interactive question dock.

`import { AskDockProvider } from "glass-ux/ai"`

[Live examples](https://dastari.github.io/glass-ux/components/ask-dock-provider)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| children | `ReactNode` | See type | yes | — | The content or component slots rendered inside the component. |
| narrow | `boolean \| undefined` | false, true | no | false | A narrow conversation (the docked pane) starts with the dock folded to one line. |

Standard React DOM attributes and events are accepted wherever the component extends a native element. The online API page lists those inherited properties as well.
