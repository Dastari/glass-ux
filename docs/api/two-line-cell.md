# TwoLineCell

Two stacked lines: a value and a data subtitle ("Windows 11 Business" / "10.0.26300").

`import { TwoLineCell } from "glass-ux/data-table"`

[Live examples](https://dastari.github.io/glass-ux/components/two-line-cell)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| subtitle | `ReactNode` | See type | no | — | Data shown beneath or beside the title. |
| title | `ReactNode` | See type | yes | — | The heading or title content. |
