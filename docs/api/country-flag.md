# CountryFlag

A 3:2 flag the height of an icon. Decorative: the country's name or code is always beside it.

`import { CountryFlag } from "glass-ux/country-select"`

[Live examples](https://dastari.github.io/glass-ux/components/country-flag)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| className | `string \| undefined` | See type | no | — | Classes applied to the outer element for layout. Use the component props and theme tokens for its appearance. |
| code | `string` | See type | yes | — | ISO 3166-1 alpha-2 ("AU"). |
