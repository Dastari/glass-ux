# TabsSkeleton

Placeholder strip with the same height and rhythm as the real tabs.

`import { TabsSkeleton } from "glass-ux/tabs"`

[Live examples](https://dastari.github.io/glass-ux/components/tabs-skeleton)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| className | `string \| undefined` | See type | no | — | Classes applied to the outer element for layout. Use the component props and theme tokens for its appearance. |
| count | `number \| undefined` | See type | no | 4 | How many tabs to stand in for. |
| icons | `boolean \| undefined` | false, true | no | true | Icons supplied for the supported choices. |
