# DropZoneScope

Draggables inside belong to `zoneId` (for zones built with `useDropZone`).

`import { DropZoneScope } from "glass-ux/drag-drop"`

[Live examples](https://dastari.github.io/glass-ux/components/drop-zone-scope)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| children | `ReactNode` | See type | no | — | The zone's content. |
| zoneId | `string` | See type | yes | — | The zone the Draggables inside belong to. |
