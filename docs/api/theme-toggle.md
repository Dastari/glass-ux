# ThemeToggle

Quick light/dark switch, for products that want it in the bar. Glass UX keeps it in the account menu.

`import { ThemeToggle } from "glass-ux/shell"`

[Live examples](https://dastari.github.io/glass-ux/components/theme-toggle)
