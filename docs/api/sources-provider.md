# SourcesProvider

Make a message's sources available to the citation markers in its text.

`import { SourcesProvider } from "glass-ux/ai"`

[Live examples](https://dastari.github.io/glass-ux/components/sources-provider)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| children | `ReactNode` | See type | yes | — | The content or component slots rendered inside the component. |
| sources | `AiSource[] \| undefined` | See type | yes | — | Citations or data sources associated with the content. |

Standard React DOM attributes and events are accepted wherever the component extends a native element. The online API page lists those inherited properties as well.
