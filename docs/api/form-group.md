# FormGroup

Related rows under an overline label; groups are separated by --gap-section (R15.8).

`import { FormGroup } from "glass-ux/form"`

[Live examples](https://dastari.github.io/glass-ux/components/form-group)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| className | `string \| undefined` | See type | no | — | Classes applied to the outer element for layout. Use the component props and theme tokens for its appearance. |
| label | `ReactNode` | false, true | yes | — | Overline group label ("Placement", "Behaviour"). |

Standard React DOM attributes and events are accepted wherever the component extends a native element. The online API page lists those inherited properties as well.
