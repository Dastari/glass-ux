# FileGlyph

The file's type glyph as an element (a static component per type).

`import { FileGlyph } from "glass-ux/ai"`

[Live examples](https://dastari.github.io/glass-ux/components/file-glyph)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| mime | `string \| undefined` | See type | no | — | Media type of the file. |
| name | `string` | See type | yes | — | The component’s name or native form field name, as specified by its value type. |
