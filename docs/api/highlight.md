# Highlight

`text` with the parts matching `query` emphasised (case- and diacritic-insensitive).

`import { Highlight } from "glass-ux/combobox"`

[Live examples](https://dastari.github.io/glass-ux/components/highlight)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| query | `string` | See type | yes | — | Current search text or typed query state. |
| text | `string` | See type | yes | — | Plain text rendered or copied by the component. |

Standard React DOM attributes and events are accepted wherever the component extends a native element. The online API page lists those inherited properties as well.
